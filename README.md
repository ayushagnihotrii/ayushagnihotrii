### ⚡ &nbsp;About Me

Hey, I'm **Ayush** — a full-stack developer and security enthusiast based in India. I specialize in building performant web applications, automated monitoring pipelines, and modern community safety tools. Most of my work centers around TypeScript, Python, React, and NestJS, with an emphasis on responsive architecture and dependable system design.

- 💻 Writing primary production code in **TypeScript** & **Python**
- 🛡️ Deep interest in **Cybersecurity**, automated threat filtering, and defensive architecture
- 📈 Creator of [**StockScout**](https://github.com/ayushagnihotrii/StockScout) — Automated stock monitoring pipeline with instant Telegram triggers
- 🛡️ Architecting [**orbit / SafeSpace**](https://github.com/ayushagnihotrii/orbit) — Scalable moderation platform built on NestJS & FastAPI
- 🛒 Developed [**Swap-Society**](https://github.com/ayushagnihotrii/Swap-Society) (student marketplace) & [**kaizen**](https://github.com/ayushagnihotrii/kaizen) (streak habit tracker)
- 💡 Always looking forward to collaborating on high-impact full-stack or security products
